# 004. Удаление категории

**Как** пользователь, **я хочу** удалить ненужную категорию, перенеся её операции в другую, **чтобы** упростить список категорий и не потерять историю.

## Критерии приёмки

### Категория без операций
- **Дано** в категории нет операций и подкатегорий
- **Когда** пользователь удаляет её
- **Тогда** она удаляется после подтверждения

### Выбор категории для переноса
- **Дано** в категории «Обеды в городе» есть операции
- **Когда** пользователь удаляет её
- **Тогда** приложение просит выбрать категорию, в которую перенести операции; родительская категория («Питание») предлагается в списке наравне с остальными

### Перенос операций
- **Дано** пользователь выбрал категорию для переноса
- **Когда** он подтверждает удаление
- **Тогда** все операции удаляемой категории относятся к выбранной, суммы в отчётах сохраняются, а удалённая категория больше нигде не показывается

### Категория верхнего уровня
- **Дано** удаляется категория верхнего уровня с операциями
- **Когда** приложение просит выбрать категорию для переноса
- **Тогда** можно выбрать любую другую подходящую категорию

### Подходящие категории
- **Дано** в удаляемой категории есть расходы
- **Когда** пользователь выбирает категорию для переноса
- **Тогда** среди вариантов нет категорий с признаком «для доходов»

### Категория с подкатегориями
- **Дано** у категории верхнего уровня есть подкатегории
- **Когда** пользователь пытается её удалить
- **Тогда** приложение не удаляет её и сообщает, что сначала нужно удалить подкатегории (каждую — с выбором, куда перенести её операции)

### Отмена
- **Дано** пользователь начал удаление
- **Когда** он отменяет его
- **Тогда** категория и её операции остаются без изменений
