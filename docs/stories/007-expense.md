# 007. Ввод расхода

**Как** пользователь, **я хочу** быстро внести расход, **чтобы** знать, куда уходят мои деньги.

## Критерии приёмки

### Поля
- **Дано** пользователь добавляет расход
- **Когда** открывается форма
- **Тогда** в ней есть дата, счёт, категория, сумма и малозаметное поле комментария

### Значения по умолчанию
- **Дано** пользователь добавляет расход
- **Когда** открывается форма
- **Тогда** дата по умолчанию — сегодня

### Выбор категории
- **Дано** пользователь выбирает категорию
- **Когда** он открывает список категорий
- **Тогда** в нём есть только категории с признаком «для расходов» или «для расходов и доходов», подкатегории видны вместе со своими родительскими

### Сохранение
- **Дано** пользователь заполнил счёт, категорию и сумму
- **Когда** он сохраняет расход
- **Тогда** операция получает следующий порядковый номер в своём дне, появляется на главном экране, а остаток счёта уменьшается на сумму

### Валюта
- **Дано** выбран долларовый счёт
- **Когда** пользователь вводит сумму
- **Тогда** сумма считается в долларах

### Обязательные поля
- **Дано** не заполнены счёт, категория или сумма
- **Когда** пользователь пытается сохранить
- **Тогда** расход не сохраняется, приложение показывает, чего не хватает

### Комментарий необязателен
- **Дано** пользователь не заполнил комментарий
- **Когда** он сохраняет расход
- **Тогда** расход сохраняется

### Прошедшая дата
- **Дано** пользователь забыл внести трату вчера
- **Когда** он вносит расход с вчерашней датой
- **Тогда** расход встаёт в конец вчерашнего дня

## Открытые вопросы

- Можно ли выбрать категорию верхнего уровня, у которой есть подкатегории.
