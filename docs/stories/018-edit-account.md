# 018. Редактирование счёта

**Как** пользователь, **я хочу** при щелчке на существующем счёте открывать модальное окно редактирования с текущими значениями полей, **чтобы** изменять параметры счёта в том же интерфейсе, что и при создании.

## Критерии приёмки

### Модальное окно при щелчке на счёте
- **Дано** пользователь на вкладке «Счета»
- **Когда** он щёлкает по строке существующего счёта
- **Тогда** открывается модальное окно редактирования

### Поля заполнены текущими значениями
- **Дано** модальное окно редактирования открыто
- **Когда** пользователь смотрит на поля
- **Тогда** поля содержат текущие значения счёта: «Название», «Валюта», «Начальный остаток», «Кредитный лимит», «Комментарий»

### Сохранение изменений
- **Дано** пользователь изменил значения в модальном окне
- **Когда** он нажимает кнопку «Ок»
- **Тогда** изменения сохраняются, модальное окно закрывается

### Отмена редактирования
- **Дано** пользователь открыл модальное окно редактирования
- **Когда** он нажимает кнопку «Отмена»
- **Тогда** модальное окно закрывается без сохранения изменений

## Не входит

- Редактирование счёта с операциями (ограничения на смену валюты) — проверяется вручную.
- Удаление и закрытие счетов.
