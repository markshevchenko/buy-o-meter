# 003. Настройка категорий

**Как** пользователь, **я хочу** добавлять, переименовывать и перемещать категории и задавать, для расходов они или для доходов, **чтобы** категории соответствовали моему образу жизни.

## Критерии приёмки

### Категория верхнего уровня
- **Дано** пользователь в настройках категорий
- **Когда** он добавляет категорию верхнего уровня с названием и признаком применимости
- **Тогда** она появляется в дереве категорий

### Подкатегория наследует настройки
- **Дано** есть категория «Питание» с признаком «для расходов»
- **Когда** пользователь добавляет в неё подкатегорию «Продукты»
- **Тогда** у «Продуктов» по умолчанию признак «для расходов», и его можно изменить до или после сохранения

### Не больше двух уровней
- **Дано** «Продукты» — подкатегория «Питания»
- **Когда** пользователь пытается добавить подкатегорию в «Продукты»
- **Тогда** приложение этого не позволяет

### Переименование
- **Дано** есть категория с операциями
- **Когда** пользователь её переименовывает
- **Тогда** все её операции показываются с новым названием

### Перемещение
- **Дано** «Обеды в городе» — подкатегория «Питания»
- **Когда** пользователь перемещает её в другую категорию верхнего уровня
- **Тогда** её операции учитываются в итогах новой родительской категории и больше не учитываются в «Питании»

### Изменение признака
- **Дано** у категории признак «для расходов»
- **Когда** пользователь меняет его на «для расходов и доходов»
- **Тогда** категорию можно выбрать и при вводе дохода

### Признак не затрагивает внесённые операции
- **Дано** у категории признак «для расходов и доходов», и в ней есть доходы
- **Когда** пользователь меняет признак на «для расходов»
- **Тогда** изменение сохраняется, внесённые доходы остаются в этой категории и учитываются в отчётах; признак влияет только на список категорий при вводе

### Выбор категории при вводе
- **Дано** у категории признак «для доходов»
- **Когда** пользователь вводит расход
- **Тогда** этой категории нет среди предлагаемых

### Категорию с подкатегориями нельзя вложить в другую
- **Дано** у категории верхнего уровня «Питание» есть подкатегории
- **Когда** пользователь пытается переместить «Питание» внутрь другой категории
- **Тогда** приложение этого не позволяет, потому что получился бы третий уровень
