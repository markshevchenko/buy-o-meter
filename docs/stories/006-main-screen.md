# 006. Главный экран: последние операции и быстрое добавление

**Как** пользователь, **я хочу** при открытии приложения сразу видеть последние операции и быстро добавлять новую, **чтобы** вносить траты сразу после покупки, не тратя на это время.

## Критерии приёмки

### Главный экран при открытии
- **Дано** пользователь вошёл
- **Когда** он открывает приложение
- **Тогда** первым он видит список своих последних операций

### Группировка и порядок
- **Дано** есть операции за несколько дней
- **Когда** пользователь смотрит список
- **Тогда** операции сгруппированы по дням, свежие дни сверху, внутри дня операции идут в порядке порядкового номера

### Содержимое строки
- **Дано** в списке есть операции разных типов
- **Когда** пользователь смотрит на строку операции
- **Тогда** он видит тип операции, сумму с валютой и счёт; для расхода и дохода — категорию; для перевода — оба счёта (и обе суммы, если валюты разные); для долга и возврата — контрагента

### Быстрое добавление
- **Дано** пользователь на главном экране
- **Когда** он хочет внести операцию
- **Тогда** кнопка добавления доступна сразу, без перехода в другие разделы, и позволяет выбрать любой тип операции

### Новая операция в списке
- **Дано** пользователь добавил операцию
- **Когда** он возвращается на главный экран
- **Тогда** операция видна в списке в своём дне

### Пустой список
- **Дано** у пользователя ещё нет операций
- **Когда** он открывает главный экран
- **Тогда** он видит приглашение добавить первую операцию

### Переход к редактированию
- **Дано** в списке есть операция
- **Когда** пользователь выбирает её
- **Тогда** открывается её редактирование (см. [012](012-edit-delete-operation.md))

### Более ранние операции
- **Дано** операций больше, чем помещается на экране
- **Когда** пользователь прокручивает список вниз
- **Тогда** он видит более ранние операции

## Не входит

- Фильтры по счёту, категории, периоду.
