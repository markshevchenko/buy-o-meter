# 005. Счета

**Как** пользователь, **я хочу** завести свои счета (наличные, карты, вклады) с валютой и начальным остатком, **чтобы** вести учёт по каждому месту, где лежат мои деньги.

## Критерии приёмки

### Создание счёта
- **Дано** пользователь вошёл
- **Когда** он создаёт счёт с названием, валютой и начальным остатком
- **Тогда** счёт появляется в списке счетов, его остаток равен начальному

### Разные валюты
- **Дано** у пользователя есть рублёвый счёт
- **Когда** он создаёт счёт в долларах
- **Тогда** остатки каждого счёта показываются в его валюте и не складываются между собой

### Тип в названии
- **Дано** пользователь создаёт счёт
- **Когда** он заполняет поля
- **Тогда** отдельного поля «тип счёта» нет, тип отражается в названии («Наличные», «Карта Сбер», «Вклад»)

### Остаток
- **Дано** у счёта начальный остаток 10 000 и по нему есть операции
- **Когда** пользователь смотрит остаток
- **Тогда** остаток равен начальному плюс доходы, полученные переводы, взятые долги и полученные возвраты минус расходы, отправленные переводы, выданные долги и отданные возвраты

### Редактирование
- **Дано** счёт существует
- **Когда** пользователь меняет название или начальный остаток
- **Тогда** изменения сохраняются, текущий остаток пересчитывается

### Счёт обязателен для операций
- **Дано** у пользователя нет ни одного счёта
- **Когда** он пытается добавить операцию
- **Тогда** приложение предлагает сначала создать счёт

## Открытые вопросы

- Можно ли менять валюту счёта, если по нему уже есть операции.
- Закрытие и удаление счетов с сохранением истории — не в первой версии.
