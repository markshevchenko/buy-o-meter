# 017. Логика при старте и создание счёта

**Как** пользователь, **я хочу** при первом запуске приложения сразу видеть вкладку Счета с подсказкой и возможностью создать счёт, **чтобы** быстро начать работу с приложением.

## Критерии приёмки

### Переключение на вкладку Счета при отсутствии счетов
- **Дано** пользователь вошёл
- **Когда** у него нет ни одного счёта
- **Тогда** приложение автоматически переключается на вкладку «Счета»

### Подсказка при отсутствии счетов
- **Дано** пользователь на вкладке «Счета»
- **Когда** у него нет ни одного счёта
- **Тогда** он видит текст: «Для начала заведите ваши счета: один счёт для каждой наличной валюты, которой вы пользуетесь, по одному счёту на каждую карту и на каждый открытый счёт в банке.»

### Таблица счетов
- **Дано** у пользователя есть хотя бы один счёт
- **Когда** он смотрит на вкладку «Счета»
- **Тогда** он видит таблицу с колонками «Название» и «Остаток», где остаток показывается в валюте счёта (например, «Наличные 1378,24₽»)

### Кнопка создания счёта
- **Дано** пользователь на вкладке «Счета»
- **Когда** он смотрит под таблицу счетов
- **Тогда** он видит кнопку «Создать счёт»

### Модальное окно создания счёта
- **Дано** пользователь нажал кнопку «Создать счёт»
- **Когда** открывается модальное окно
- **Тогда** он видит поля:
  - «Название» (текстовое поле, не может быть пустым после удаления пробелов в начале и конце)
  - «Валюта» (выпадающий список с валютами на русском, хранение в кодах)
  - «Начальный остаток» (можно вводить сумму, в том числе отрицательную)
  - «Кредитный лимит» (только для кредитной карты, можно вводить только положительную сумму)
  - «Комментарий» (поле может быть пустым)

### Создание счёта
- **Дано** пользователь заполнил поля в модальном окне
- **Когда** он нажимает кнопку «Ок»
- **Тогда** счёт создаётся и записывается на Google Drive, появляется в таблице счетов, модальное окно закрывается

### Отмена создания счёта
- **Дано** пользователь открыл модальное окно создания счёта
- **Когда** он нажимает кнопку «Отмена»
- **Тогда** модальное окно закрывается без создания счёта

### Исчезновение подсказки
- **Дано** пользователь видит подсказку на вкладке «Счета»
- **Когда** появляется первый счёт
- **Тогда** подсказка исчезает

## Не входит

- Редактирование существующих счетов (уже реализовано в истории 015).
- Закрытие и удаление счетов.
